# Портфолио

Персональная страница: кто я, чем занимаюсь, проекты, навыки, контакты.

**Сайт:** https://runik2.github.io/portfolio/

## Как устроено

- `index.html` — разметка, стили и рендер (один файл, без зависимостей)
- `data.json` — весь контент: имя, о себе, проекты, навыки, контакты

Чтобы что-то поменять — правится только `data.json`. Страница перечитывает его при загрузке.

## Запуск локально

```bash
python -m http.server 8000
```

Открыть http://localhost:8000 — просто двойной клик по `index.html` не сработает,
потому что `fetch` к локальному JSON блокируется браузером.

## Структура проекта в data.json

```json
{
  "title": "Название",
  "desc": "Одно-два предложения по делу",
  "stack": ["Технологии"],
  "url": "ссылка на репозиторий",
  "demo": "ссылка на живой демо-сайт (необязательно)",
  "group": "продукты | автоматизация | учёба",
  "featured": true
}
```

`featured: true` добавляет оранжевую полоску слева — для проектов, которые не стыдно показать первыми.
